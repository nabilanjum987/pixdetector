The problem: a whole paragraph typed with Caps Lock on

It happens to everyone: you look up and realise the last two paragraphs were typed with Caps Lock on, or a headline pasted from a spreadsheet is in the wrong case, or a variable name needs to be camelCase and you have it as a sentence. The complaints are always the same three. First, retyping: people retype whole blocks by hand because they do not know a converter exists. Second, title case done wrong: naive tools capitalise every word, but real title style (Chicago, AP) lowercases short words like “and”, “of” and “the” mid-title — and people argue about which is right. Third, the tools that do exist are either buried in a word processor menu, or they convert one case at a time and make you copy-paste back and forth. What people want is the simplest possible fix: paste once, click the case, copy the result — and for developers, the code cases (camelCase, snake_case, kebab-case) in the same place as the writing cases.

Which case should I use for file names?

kebab-case is the web convention: lowercase, hyphens, no spaces. URLs and most static hosts treat it most predictably. snake_case is the convention for Python code and database columns, camelCase for JavaScript variables, and PascalCase for classes and components. For a document title, use Title Case — but remember this tool capitalises every word, while strict style guides lowercase short words like “and”, “of” and “the” in the middle of a title; fix those few by hand if your style guide requires it.

Can it fix text typed with Caps Lock on?

Yes — that is its most common use. Paste the all-caps text, click lowercase or Sentence case, and copy the fixed version. It takes one click instead of retyping the whole block.

What is the difference between Title Case and Sentence case?

Title Case capitalises the first letter of every word, as in a headline. Sentence case capitalises only the first letter of each sentence, as in normal body text. This tool's Title Case capitalises every word, including short ones like “of” and “the”.

Does Sentence case handle the pronoun “I” and proper nouns?

No — honestly, it does not. Sentence case capitalises sentence starts only. Names like “Delhi” or the pronoun “I” mid-sentence are not auto-recognised, so give the result a quick manual pass.
