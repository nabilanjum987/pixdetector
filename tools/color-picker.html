The problem: three people, three different codes

Every designer hits the same moment: you choose an orange for a button, your developer asks for the HEX code, your designer sends RGB values, and the stylesheet needs HSL. The colour itself is not the problem — the translation is. People waste time hunting through ad-heavy tool pages where the actual hex code is the hardest thing to find, or they guess a hex value by eye and land a shade off. Others open Photoshop just to read one code from a swatch. What people want is one small page: pick the colour, see HEX, RGB and HSL side by side, and copy the one they need in a single click — then get on with the work.

What is a colour picker?

A colour picker is a tool that lets you choose any colour and gives you its code in the formats design and code actually use. Drag the square to set saturation and brightness, slide the hue bar, or type a HEX code — this page then shows the colour as HEX, RGB and HSL, each with a one-click copy button, plus five lighter tints and five darker shades. It is free, with no signup, and everything runs in your browser. This page picks colours; it does not extract them from images — that is the Color Picker from Image.

HEX, RGB and HSL describe the same colour in different notation. HEX writes the red, green and blue channels in base 16 after a hash — #3B82F6 is the same colour as rgb(59, 130, 246). HSL describes it as hue (0–360° around the colour wheel), saturation and lightness, which is the easiest format to adjust by hand: "make it a bit lighter" is just nudging the lightness up.

What is this colour called?

Every picked colour shows its closest named colour underneath the codes, with how close the match is. Names are nearest-match labels from a list of common named colours — only the 148 CSS names are exact identities, so a close match is a useful label, not a proof that the colour "is" that name. If the match is distant, trust the HEX code, not the name.

How do I build a palette from one colour?

Start with your base colour, then use the tints and shades row: five lighter versions (mixed toward white) and five darker versions (mixed toward black) of the same hue. A practical palette is one base colour, one or two tints for backgrounds, and one dark shade for text. Before you ship text in any of those colours, run the pair through the Color Contrast Checker — WCAG asks for at least 4.5:1 for normal text and 3:1 for large text, and a pretty tint often fails that test.

FAQ

What is a HEX colour code?

Three bytes in hexadecimal: #3da5ff is red 3d (61), green a5 (165), blue ff (255); 256 levels per channel, 16.7 million combinations. Shorthand #f0c expands to #ff00cc; an 8-digit hex adds alpha (#3da5ff80 is about 50% opacity). HEX and RGB are the same colour in different notation.

How do I get the HEX code of a colour on my screen?

In Chrome, Edge, Brave or Opera, use this page's “Pick from screen” eyedropper and click the pixel. In Safari or Firefox, take a screenshot and upload or paste it into an image colour picker instead — the screen API is Chromium-only.

Are HEX and RGB the same colour?

Yes — the same sRGB value, different notation. HSL is the same colour expressed as hue, saturation and lightness, which is nicer for building lighter and darker variants by hand.

What contrast ratio do I need for text?

WCAG AA asks for 4.5:1 for normal body text and 3:1 for large text (roughly 18pt and up); AAA is 7:1. Check the pairing, not the colour alone — this page shows the ratio against white and black as you pick.

How do I use a picked colour in CSS?

Copy the HEX value and paste it as a CSS value, for example color: #3B82F6; or background: #3B82F6;. The RGB and HSL values paste the same way, and the CSS variable line (--color: #3B82F6;) lets you reuse one colour across a stylesheet.

Can this picker get a colour from an image?

No — this page picks colours from a wheel and swatches. To sample a colour from a photo or screenshot, use the Color Picker from Image, which reads the exact pixel you click.

What is HSL good for?

HSL describes a colour as hue, saturation and lightness, which matches how people think about colour. To make a colour lighter, raise the lightness; to mute it, lower the saturation — no hex maths needed.

Does the picker work on my phone?

Yes. Drag the square and the hue slider with your finger, or type a HEX code. The copy buttons work on mobile browsers too. The screen eyedropper does not work on phones — screenshot the colour and upload it to the Color Picker from Image instead.

Can I save colours for later?

Yes — press “Save this colour” and it is kept in this browser and survives reloads. Recent colours are saved automatically too; click a saved swatch to load it, or a recent one to copy its HEX.

What are the tints, shades and harmonies for?

Tints are your colour mixed toward white and shades toward black — five of each here. Harmonies are colours that sit in a fixed relationship to your hue: complementary (opposite), analogous (neighbours) and triadic (a third of the wheel apart). Click any of them to load it as your colour.

Why does my colour look different in print?

Screens use RGB light; printers use CMYK ink, and a bright screen colour often prints duller. The CMYK readout here is an estimate, not print-accurate — convert properly before sending work to print. Sampled values are sRGB, so a Display P3 photo's hex is a clipped approximation.

What is the 8-digit HEX code for?

It is a HEX code with opacity built in: the last two digits are the alpha channel, FF for fully opaque down to 00 for fully transparent. Use the opacity slider above, then copy the HEX8 or RGBA value for fades and overlays.
