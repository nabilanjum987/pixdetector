The problem: three people, three different codes

Every designer hits the same moment: you choose an orange for a button, your developer asks for the HEX code, your designer sends RGB values, and the stylesheet needs HSL. The colour itself is not the problem — the translation is. People waste time hunting through ad-heavy tool pages where the actual hex code is the hardest thing to find, or they guess a hex value by eye and land a shade off. Others open Photoshop just to read one code from a swatch. What people want is one small page: pick the colour, see HEX, RGB and HSL side by side, and copy the one they need in a single click — then get on with the work.

What is a colour picker?

A colour picker is a tool that lets you choose any colour and gives you its code in the formats design and code actually use. Drag the square to set saturation and brightness, slide the hue bar, or type a HEX code — this page then shows the colour as HEX, RGB and HSL, each with a one-click copy button, plus five lighter tints and five darker shades. It is free, with no signup, and everything runs in your browser. This page picks colours; it does not extract them from images — that is the Color Picker from Image.

HEX, RGB and HSL describe the same colour in different notation. HEX writes the red, green and blue channels in base 16 after a hash — #3B82F6 is the same colour as rgb(59, 130, 246). HSL describes it as hue (0–360° around the colour wheel), saturation and lightness, which is the easiest format to adjust by hand: "make it a bit lighter" is just nudging the lightness up.

How do I build a palette from one colour?

Start with your base colour, then use the tints and shades row: five lighter versions (mixed toward white) and five darker versions (mixed toward black) of the same hue. A practical palette is one base colour, one or two tints for backgrounds, and one dark shade for text. Before you ship text in any of those colours, run the pair through the Color Contrast Checker — WCAG asks for at least 4.5:1 for normal text and 3:1 for large text, and a pretty tint often fails that test.

FAQ

Is this color picker really free?

What is the difference between HEX and RGB?

They describe the same colour in different notation. RGB uses three numbers from 0 to 255; HEX writes those same numbers in hexadecimal after a hash. #3B82F6 and rgb(59, 130, 246) are the identical colour.

Can this picker get a colour from an image?

No — this page picks colours from a wheel and swatches. To sample a colour from a photo or screenshot, use the Color Picker from Image, which reads the exact pixel you click.

What is HSL good for?

HSL describes a colour as hue, saturation and lightness, which matches how people think about colour. To make a colour lighter, raise the lightness; to mute it, lower the saturation — no hex maths needed.

How do I use a picked colour in CSS?

Copy the HEX value and paste it as a CSS value, for example color: #3B82F6; or background: #3B82F6;. The RGB and HSL values paste the same way.

Does the picker work on my phone?

Related questions

How do I find the name of a colour? This tool gives you codes, not names — a hex code has no built-in name, so note the code itself in your palette.

What is the shorthand hex form? #FA3 expands to #FFAA33 by doubling each digit. It only works when both digits of each pair match, so most real colours cannot use it.

Can I save colours for later? Not on this page — copy the codes into your notes or stylesheet. The tints and shades row rebuilds from any colour you paste back in.

Why does my colour look different in print? Screens use RGB light; printers use CMYK ink. A bright screen colour often prints duller — convert to CMYK before sending work to print.
