The problem: Excel quietly destroys your CSV data

It is the most common spreadsheet complaint on the internet, and it bites people who did nothing wrong. You export a customer list or an order report as CSV, double-click it, and Excel "helpfully" guesses what every cell is. A zip code of 01234 loses its zero and becomes 1234. A 15-digit order ID turns into 1.05E+14. A phone number starting with 0 loses the 0. A fraction like 3/8 becomes a date, 08-Mar. And if you then save the file, the original values are gone — the zeros were never in the saved file at all, because Excel rewrote them the moment it opened the CSV. Forum threads are full of shop owners who exported their whole inventory to CSV, re-imported it, and found every SKU barcode wrong with no way to get the zeros back. The proper fix in Excel is a fiddly import wizard where you mark each column as Text by hand — or you convert the CSV to a real .xlsx first, with the types decided correctly, and never let Excel guess again.

Numbers, leading zeros and dates — the exact rules

Ordinary numbers like 49.99 or 1200 become real numbers in the workbook, so SUM, AVERAGE and sorting work. A value that starts with a zero (01234, 0555123456) or is too long to be a safe number (a 15-digit order ID) stays as text, so nothing is lost. Dates stay as text exactly as written, so Excel cannot flip 03/04 into April 3rd or March 4th depending on your locale. If a whole column needs a different rule, use the per-column type picker above the preview: set the column to Text, Number, Date or Auto before you download — that is the same choice Microsoft's own import wizard asks for, built into the preview grid. For full control beyond that, use Excel's import wizard instead.

When a CSV is the wrong tool entirely

CSV is a transfer format, not a working format. If you keep opening the same CSV, editing it and saving it back, you will lose data sooner or later — Excel rewrites types on every open. Convert once to .xlsx and work in the workbook from then on. Keep the original CSV as the backup, untouched.

FAQ

Is this CSV to Excel converter really free?

How do I convert a CSV file to Excel?

Upload the CSV here, check the preview grid, set any column types that need forcing to Text, and download the .xlsx — or in Excel use Data > Get Data > From Text/CSV and set column types before loading.

Why does Excel delete the leading zeros in my CSV?

Because Excel guesses that a cell full of digits is a number, and numbers do not keep leading zeros — so 01234 becomes 1234 and a long order ID becomes 1.05E+14. This converter keeps values that start with a zero as text, so 01234 stays 01234 in the .xlsx, while ordinary numbers are stored as real numbers you can sum.

Why does Excel turn my long numbers into scientific notation?

Excel stores at most 15 digits of precision and displays longer digit strings in exponential form; format the column as Text before the data lands, or the digits are lost. This converter writes digit-heavy values as text automatically, and the per-column picker lets you force any column to Text.

Why does my CSV open with everything in one column?

Excel expected a different separator than the file uses — common with European semicolon files. Re-import and set the delimiter by hand, or pick the delimiter here (Auto-detect, comma, semicolon, tab, pipe or a custom character).

What is the difference between CSV and XLSX?

CSV is plain text — rows and commas, no formatting, formulas or sheets. XLSX is a real workbook with formatting, formulas, multiple sheets and types.

Does it make a real .xlsx file?

Yes. The download is a genuine Excel workbook (.xlsx) that opens in Excel, Google Sheets, LibreOffice and Apple Numbers — not a CSV file renamed to .xlsx. Numbers are stored as real numbers, and the first row becomes the header row when you tick that option.

What if my CSV uses semicolons instead of commas?

That is common in European exports, where the comma is the decimal separator. Pick Semicolon in the delimiter menu, or leave it on Auto and the tool detects the delimiter from the first lines. Tab-separated files work the same way.

Why does Excel change my dates when I open a CSV?

Excel guesses the type of every value and turns date-like strings into dates in the local format; importing with the column set to Text keeps the string unchanged. This converter keeps dates as text by default.

Can I keep my formatting when converting CSV to Excel?

There is no formatting in a CSV to keep — you add it after conversion (header colours, bold headers, freeze panes). This converter writes plain data with correct types; add formatting in Excel after opening the workbook.

How do I convert multiple CSV files into one Excel workbook?

This converter handles one file per run. Convert each CSV to its own .xlsx, then copy the sheets into one workbook in Excel — or import each CSV into its own sheet directly in Excel.

Does converting CSV to Excel work without Excel installed?

Yes — this browser converter reads the file locally and downloads a real .xlsx you can open in Excel, Google Sheets, LibreOffice or Numbers later.

What does “Excel-safe numbers” mean?

A converter option that writes digit-heavy values (IDs, phone numbers, zip codes) as text so Excel cannot reformat them into scientific notation or strip zeros. This converter does it automatically for leading-zero and very long values, and the per-column Text picker forces it for any column.

How big a CSV can I convert?

Everyday exports — thousands of rows — convert instantly. Very large files with hundreds of thousands of rows still work but take longer and use more memory, so on a phone keep it to smaller files. Excel itself caps a sheet at 1,048,576 rows.
