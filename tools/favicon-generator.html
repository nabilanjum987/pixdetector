The problem: the favicon is blurry, or it never shows up at all

Favicon complaints come in two flavours, and both are maddening. The first is the blurry 16-pixel icon: a detailed logo that looks perfect at 512 pixels turns into grey mush in a browser tab, because at 16×16 there are only 256 pixels to draw with — and if the artwork's edges do not line up with the pixel grid, every stroke comes out half-grey. The second is the favicon that simply never appears: the file is in the wrong folder, the HTML link tag is missing or mistyped, or the browser is showing a cached old icon from days ago and no amount of refreshing seems to fix it. People want a free generator that shows the icon at its real sizes before they download it, gives them a proper multi-size .ico file (not a renamed PNG), and hands them the exact HTML to paste — so the icon actually shows up.

Why is my favicon not showing up?

Almost always one of four things. First, the files are not where the HTML says they are — upload them to the site's root folder and open the favicon.ico URL directly in your browser to check it loads. Second, the link tag is missing or mistyped — use the snippet from this page, with the leading slash. Third, the browser cached the old icon (or the absence of one): hard-refresh with Ctrl+Shift+R, test in an incognito window, or add ?v=2 to the href to force a fresh fetch. Fourth, Google search results show favicons on their own schedule — a new favicon can take days to appear there even when it works in tabs. If the icon loads at its direct URL and shows in incognito, the setup is right and the rest is cache.

Why isn't it showing? The troubleshooter

The icon is uploaded and correct, but the tab still shows the old icon or a globe. Work through this list in order:

  1. Test in incognito — if it shows there, it is cache, not your files.
  2. Open yoursite.com/favicon.ico directly — if it 404s, the file is in the wrong folder or the path is wrong.
  3. Check the link tag — use the snippet from this page, with the leading slash, in the <head>.
  4. Hard refresh — Ctrl+Shift+R (Cmd+Shift+R on Mac).
  5. Add ?v=2 to the link href and increment it on every update, to force a fresh fetch.
  6. Clear the favicon cache via chrome://favicon-internals, then wait — a new favicon can take hours to days to appear everywhere, including Google search results.

FAQ

What is a favicon?

The small icon beside your page title in the browser tab, bookmarks and search results; it identifies your site among many open tabs.

What size should a favicon be?

There is no single size: favicon.ico holds 16/32/48 px, apple-touch-icon is 180×180, PWA icons are 192 and 512 px, and the SVG scales to any size. This tool gives you the .ico plus 16/32/48/180 PNGs.

Do I still need a favicon.ico file?

Yes — it is the legacy/desktop fallback older browsers and Google still read; ship a multi-size .ico with 16, 32 and 48 px, and let modern browsers prefer the SVG.

Why is my favicon not showing?

Usually browser caching (favicons are cached separately and aggressively), a wrong file path/404, or a wrong link tag. Test in incognito — if it shows there, it is cache. See the troubleshooter on this page.

How do I force a favicon refresh?

Add ?v=2 to the link href and increment on updates; or hard refresh (Ctrl+Shift+R), visit yoursite.com/favicon.ico directly and refresh it, or clear the favicon cache via chrome://favicon-internals.

How do I add a favicon to my website?

Upload the generated files to your site root, paste the provided link tags into the <head>, then clear cache and reload. This page gives you the snippet to paste.

What image should I upload to make a favicon?

A square PNG with transparent background, 512×512 px or larger; an SVG is better if you have one. This tool exports PNG and .ico — it does not output SVG.

What makes a good favicon?

A simple, bold mark that survives 16 px — wordmarks and detailed logos turn to mush; use the symbol alone, with strong letter/background contrast. Use the 16-pixel check on this page.

Can I make a favicon from text or initials?

Yes — use Letters mode on this page: type 1–2 characters, pick colours and a shape, no logo needed.

Can I make a favicon from an emoji?

Yes — use Emoji mode on this page: paste an emoji as the icon.

Is a favicon generator really free?

What is a maskable icon?

A 512×512 PWA icon whose artwork stays inside a central safe zone (~409 px circle) so Android adaptive-icon masks can crop it without cutting off the logo. This tool does not generate PWA icons or a manifest.

What is a site.webmanifest?

The PWA manifest file that declares the 192/512 icons (and maskable icon) so the site can be installed on Android home screens. This tool does not generate a manifest — its download is the core favicon set only.

Does a favicon help SEO?

It doesn't rank pages directly, but Google shows favicons in search results and a missing one hurts perceived professionalism; Google requires a square favicon over 48×48 px at a stable crawlable URL.

Can I use a PNG instead of .ico?

Modern browsers accept PNG favicons, but the .ico is still needed as the fallback for older browsers and some tooling; ship both — which is what this tool gives you.
