The problem: dots and dashes that all look alike

Morse code looks simple until you try to use it. The complaints from learners and ham-radio beginners are always the same. First, decoding: “...---...” without spaces is unreadable — one missing space turns one letter into a completely different one, and mixing up a dot and a dash count turns E into T or A into N. Second, speed: beginners start at 5 words per minute, contest operators copy 25–40, and a translator with a fixed speed is useless to both. Third, audio: people want to hear the code, not just read it — “can it play the sound?” — and most simple translators have no audio at all, or audio that clicks at the start of every beep. Fourth, the question everyone asks: “can it decode Morse from a sound file or my microphone?” The honest answer for most free translators is no — decoding live audio needs pitch detection and adaptive timing, a much harder problem than playing beeps. What people want is a translator that works both ways, plays clean audio at a speed they choose, and says plainly what it cannot do.

How fast should Morse playback be?

Speed is measured in words per minute (WPM), using the PARIS standard word. Beginners start around 5 WPM, casual operators work at 15–20 WPM, and skilled amateur radio operators often copy 25–40 WPM or more. This tool's slider runs from 5 to 40 WPM: start slow, learn each letter as one sound pattern rather than counting dots and dashes, and raise the speed only when the slow speed feels easy. A dash is three times as long as a dot; the gap between letters is three dot-lengths, and the gap between words is seven.

Is Morse code still used today?

Yes, though less than it once was. Amateur (ham) radio operators use it daily because a Morse signal gets through when voice cannot — it needs very little power and bandwidth. Aviation navigation beacons still identify themselves in Morse, and it remains a reliable emergency signalling method with light or sound when nothing else works. It is also a popular puzzle and learning tool: escape rooms, scavenger hunts and classroom activities all use it, which is why a translator with audio is the version people actually want.

Spacing is the message

Morse code is not just dots and dashes — the gaps are part of the code. A dot is 1 unit long, a dash is 3 units, the gap inside a letter is 1 unit, the gap between letters is 3 units, and the gap between words is 7 units. At a given speed, 1 unit lasts 1200 ÷ WPM milliseconds, so at 20 WPM a dot is 60 ms and a dash is 180 ms. Without those gaps, no tool can know where one letter ends and the next begins: ...---... with no spaces could be SOS, or VTB, or several other strings. A person decodes it by guessing — and so would any translator that claimed otherwise.

Why your Morse decodes as question marks

A “?” in the result almost always means the input format is off, not that the message is broken. These are the five ways it happens, with the fix for each:

Before you trust a translation — a tattoo, a puzzle answer, a message — run the round-trip check above: encode, decode, and confirm the text comes back character for character. A missing gap can turn EMMA into something else entirely, and it still looks like a name, so it is easy to miss without the check.

FAQ

Is this Morse code translator free?

What is SOS in Morse code?

SOS is ... --- ... — dot-dot-dot, dash-dash-dash, dot-dot-dot. It is the international distress signal, chosen because it is short and hard to misread. As a distress call it is sent as one unbroken signal, with no gaps between the letters.

What is HELLO in Morse code?

HELLO is .... . .-.. .-.. --- — H is four dots, E is one dot, L is dot-dash-dot-dot twice, and O is three dashes.

What is "I love you" in Morse code?

I love you is .. / .-.. --- ...- . / -.-- --- ..- — I is two dots, love is .-.. --- ...- ., and you is -.-- --- ..-.

How do I translate text to Morse code?

How do I decode Morse code into English?

Switch to “Morse → Text”, type a period (.) for a dot and a hyphen (-) for a dash, with one space between letters and a slash (/) between words. The decoder also accepts the look-alike characters • and — if you paste code from elsewhere.

Why does my Morse decode show question marks?

Almost always the spacing: double spaces between letters, no spaces at all, a slash without spaces around it, a leading or trailing space, or look-alike glyphs (• / —) copied from a web page. A “?” means that group of dots and dashes is not a character in the code — check the spacing first.

Why won't my Morse code decode?

Usually run-together code with no gaps — ...---... could be SOS or VTB or several other strings. Spacing is part of the message, and no tool can be sure where letters end without it.

Can a translator decode Morse from audio or a photo?

No — text translators read typed dots and dashes only. They can play a signal; they cannot listen to one. Decoding audio needs a dedicated audio decoder that measures tone pitch and timing, and this tool does not export MP3 or WAV either — it plays audio in the browser only.

Is Morse code a secret code / encryption?

No. Morse is fully reversible and offers no secrecy — anyone with the chart can decode it.

How fast is Morse code measured?

In words per minute (WPM), based on the standard word PARIS, which is 50 units long. Beginners learn at 5 WPM, amateur radio operators communicate at 13–25 WPM, and competitive operators exceed 35 WPM. This tool plays at 5–40 WPM, starting at 20 WPM.

What is Farnsworth speed?

Farnsworth speed controls the spacing between letters and words separately from character speed — characters are sent fast, gaps are kept long — and it is the standard way to learn by ear. This tool does not have a separate Farnsworth control: its speed slider changes all the timing together, so start slow here.

Which Morse code standard does this use?

International Morse code as defined in ITU-R M.1677-1. American railroad Morse uses different codes and is not supported by most web tools, including this one.

What characters have no Morse code?

Symbols outside the chart — # and emoji, for example. How a translator handles them differs by tool: some stop at the first one, some pass it through unchanged, some mark it #. This tool skips characters it has no code for and lists them under the result.

Is Morse code still used today?

Yes — in amateur radio, aviation, and emergency signalling, and SOS remains the international distress signal. It is also a popular puzzle and learning tool in escape rooms, scavenger hunts and classrooms.
