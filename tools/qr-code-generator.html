The problem: "free" QR codes that switch off after you print them

A restaurant prints a thousand menus with a QR code. Six months later the code opens a "this link has expired" page, because the generator sold them a dynamic code — a redirect that only works while the subscription is paid. That is the most common complaint about QR generators, and it is a nasty one: the printed square never changes, but the desk behind it closes. The other complaints are smaller but constant: download buttons hidden behind an account wall, watermarks stamped on the code, scan limits on the free plan, and no way to make a WiFi or email code without signing up. What people want is the opposite — a plain static code, made in seconds, that works forever and belongs to them.

How do I make a QR code for free?

Type your link or text above, pick a size and an error-correction level, and download the code as a PNG or SVG — free, with no signup, no watermark and no expiry, because the code is generated entirely in your browser. A QR code is your text drawn as a machine-readable grid of black and white squares. Any phone camera can read it, and because the data lives inside the image itself, there is no server in the middle that can switch it off.

Every code made here is static: the link or text is baked into the pattern, so it works offline and works forever, as long as the destination itself still exists. That is different from a dynamic code, which points at the provider's redirect and stops working when you stop paying. Static is the right choice for anything printed — menus, business cards, posters, packaging — because printed things cannot be updated anyway.

How to make a QR code in 3 steps

Step 1: pick what the code should do — a website link, plain text, a WiFi login, an email, a phone call or an SMS — and fill in the details. Step 2: choose a size (512 px suits most documents; 1024 px for posters) and an error-correction level — M is the best all-rounder. Step 3: download the PNG for screens and documents, or the SVG for professional printing, then test it with your own phone before you print a hundred copies.

Which error-correction level should I use?

Error correction is spare capacity that lets a damaged code still scan. L (low) fits the most data and suits clean screens. M (medium) is the reliable default for most uses. Q or H recover more of the pattern if the print gets dirty, wet or scratched — but the pattern gets denser for the same content, so very long links may not fit at H. Rule of thumb: use M for menus and flyers, H for anything that will live outdoors or be handled roughly. And keep the quiet zone — the white margin around the code — intact. Never crop it off; scanners need it to find the code.

How big should I print a QR code?

A useful rule: the printed code should be at least one tenth as wide as the distance people scan it from. A code scanned from 50 cm across a table should be at least 5 cm wide. The PNG here exports at up to 1024 px with a full quiet zone, which stays sharp at full-page size; the SVG scales to any size at all, which is why it is the better choice for signage and packaging. Always test-scan a proof before the print run, and remember that dark code on a light background scans best — light-on-dark codes often fail.

The “free” trap: codes that die when the trial ends

This is the most shared complaint about QR generators. Many services let you create a code free, then charge to keep it alive — one viral reel warns of a $19.99-a-month charge to “keep it alive”, with every printed code stopping if a payment is missed. The named free tiers tell the same story: QR TIGER’s free plan includes 3 dynamic codes with 500 scans each, shows a QR TIGER logo popup, and its own FAQ says editable codes stop working once the plan expires. QRCodeChimp’s free plan includes 10 dynamic codes with 1,000 scans a month shared across all codes. QR Code Monkey’s free tool is static-only — its dynamic codes are a separate paid product. A static code has none of these traps, because there is no server in the middle to switch it off.

Wi-Fi QR codes — the guest-network rule

The most copied Wi-Fi use case is a printed code taped to a fridge or a café table: guests scan it and join without typing a password. Choose the WiFi type above, enter the network name exactly as the router shows it (it is case-sensitive), the password, and the security type — WPA/WPA2 for most home networks, WEP for very old ones, or no password for an open network. The tool escapes special characters in the name and password automatically.

Use a guest network, not your main one. The password is plain text inside the code — anyone who scans it, or photographs the printed code, has it. Set up a guest network on your router, put its password in the code, and change the guest password between stays or seasons. If the password changes after the sticker is printed, the code stops connecting — print a new one. And if a code scans but will not connect, the usual cause is a typo: the network name, password or security type in the code does not match the router, often a capital letter or a trailing space. Older phones also cannot join WPA3-only networks.

To make a printable sign, download the code as an SVG, print it large with the network name and a “Scan to join the Wi-Fi” label underneath, and keep the white margin around the code intact — scanners need it to find the pattern.

Before you print: the 5-point scan check

Most unscannable codes fail on one of five things — check them before printing hundreds: 1. Size — at least 2 cm across for close scanning, bigger for posters. 2. Contrast — dark code on a light background; low-contrast brand colours fail. 3. Quiet zone — never crop the white margin. 4. Data density — keep URLs short (under about 100 characters scans most reliably); more data means a denser, harder-to-scan pattern. 5. Test it — scan the printed proof on more than one phone before the print run.

FAQ

Is this QR code generator really free?

Yes. Create and download unlimited QR codes as PNG or SVG with no signup, no watermark and no scan limit. Everything runs in your browser.

Do the QR codes expire?

No. These are static QR codes with the data encoded directly in the pattern, so they work forever as long as the destination still works. There is no subscription keeping them alive, unlike dynamic codes that stop when you stop paying.

What can I put in a QR code?

Website links, plain text, WiFi network details, email addresses with a subject and message, phone numbers that dial when scanned, and SMS messages.

Which error-correction level should I use?

M (medium) is the reliable default. Use Q or H for codes that may get dirty, wet or damaged, and L when you need to fit the most text into the code.

Should I download PNG or SVG?

PNG for screens, messages and ordinary documents. SVG for professional printing and signage, because it stays perfectly sharp at any size.

Can I track scans of my QR code?

No. This generator makes a static image with no redirect and no tracking. If you need scan analytics, you need a dynamic QR service instead.

Can I change the link after printing?

Only with a dynamic code. A static code’s link is part of the printed pattern — a different link needs a new code. Workaround: encode a URL on a site you control, and change where that page redirects.

Why won’t my QR code scan?

Usually: too small, low contrast, a cropped quiet zone, too much data making a dense pattern, or a damaged or dirty print. Start black on white, at a decent size, with short content, then get fancy — and test-scan before printing.

How do I make a QR code for Wi-Fi?

Choose the WiFi type, enter the exact network name (case-sensitive), password and security type — WPA/WPA2 for most networks — then print it. Guests scan with their phone camera and join without typing. Use a guest network, not your main one.

Why does my Wi-Fi QR code scan but not connect?

The network name, password or security type in the code does not match the router — a typo, a capital letter, a trailing space, or a password changed after the sticker was printed. Older phones also cannot join WPA3-only networks.

Can I add my logo to a QR code?

Yes in principle, if you use high error correction (H, which recovers about 30% of a damaged pattern) and keep the logo small — about 22% of the code’s width or less — and test-scan before printing. This tool does not add a logo itself: it keeps the pattern clean so it scans first time.

How much data can I put in a QR code?

Up to 4,296 alphanumeric characters technically, but more data means a denser pattern that is harder to scan — keep URLs under about 100 characters for reliable scanning.

Is it safe to put my Wi-Fi password in a QR code?

Anyone who scans or photographs the code has the password. Use a guest network, not your main one, and change the guest password between stays or seasons.

What is the quiet zone and why does it matter?

The blank white margin around the code. Scanners need it to find the pattern — never crop it away. This tool’s downloads keep the full quiet zone.

Can one QR code connect guests to Wi-Fi and open my menu?

No — a QR code holds one thing. Print the Wi-Fi code and a menu code side by side, each labelled.
