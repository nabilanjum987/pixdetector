The problem: calling on the same few people every time

Every teacher knows it: ask a question and the same three hands go up, while the rest of the class quietly checks out. Every giveaway host knows the other version: draw a winner by hand and someone in the comments says it was fixed. The complaints about name pickers follow the same pattern as the wheel — tools that ship with fake sample names you have to delete first, tools that pick the same person twice in a row with no way to stop it, and tools that make you create an account before you can use your own class list. What teachers and hosts actually want is the simplest possible thing: paste my list, pick one fairly, and do not pick the same person twice until everyone has had a turn.

Two classroom mistakes make a fair picker unfair in practice. The first is forgetting to mark absent students: they get picked, the class stalls, and the fair round quietly skews. The second is re-spinning because you do not like the result — the moment you do, everyone watching concludes the draw is only random until you disapprove of it. This page has a Here checkbox per name for the first, and a no-repeat round for the second.

How do I pick a random name from a list? The direct answer

Paste your names below, one per line, choose how many to pick, and press PICK A NAME — free, with no signup, and the pick happens instantly in your browser. With “No repeats” on, each name sits out until the whole list has had a turn. Every name has exactly the same chance.

A random name picker is a tool that chooses one or more names from a list you provide. This one has no built-in names — the list comes from you, whether that is a class register, a team roster, or a list of giveaway entrants — and the pick is made with your browser's secure random generator, so the result cannot be steered. Picks use crypto.getRandomValues() with rejection sampling, and shuffles use Fisher–Yates — the naive sort(() => Math.random() - 0.5) shuffle is biased, so this page never uses it.

How to pick a random name in 3 steps

Step 1: paste your names, one per line — copy them straight from a spreadsheet or a document. Step 2: choose how many names to pick (1 to 10) and leave "No repeats" on if nobody should be picked twice. Step 3: press PICK A NAME. When everyone has had a turn, press "Start a new round" to put all names back in.

Fair picks for classrooms

The "No repeats" mode is built for classrooms: it works like drawing names from a hat, one at a time, without putting them back. Nobody is called on twice while someone else has never been called on, which keeps the whole class paying attention — anyone could be next. When the round is over, one button resets the pool. If you want a visible draw the class can watch, the spin the wheel tool picks from the same kind of list with an animated wheel instead.

What this picker cannot do

It cannot invent names for you. If you need name ideas — for a character, a baby, a team or a business — that is a different tool: a name generator creates names, while this picker only chooses from names you already have. Your list is saved in this browser only, so it is there when you come back on the same browser — but clearing browsing data wipes it, and it never syncs to another device. That is also why nothing you paste is ever uploaded or seen by anyone else.

Fair randomness — the mechanism, in one line

Every pick is made with crypto.getRandomValues() plus rejection sampling, and shuffles use the Fisher–Yates algorithm. Math.random()-only tools are fine for games, but not for a draw anyone might challenge.

FAQ

How do I pick a random name from a list I paste?

Paste the names one per line into the box, press PICK A NAME, and one name is picked — the list never leaves your browser on the in-browser tools, and this page is one of them.

How many names can a random name picker handle?

It varies widely: some free draws take as few as 20 names, wheel tools take 100 to 500 entries, and one roster tool takes up to 20,000. This picker takes up to 500 names.

Can I use a random picker for a giveaway or raffle?

Yes — paste the entrants, draw live on screen, remove each winner so nobody wins twice, and record your screen so the draw is provable.

How do I pick a random student fairly in class?

Paste the class list, mark absent students with the Here checkbox, leave “No repeats” on, and pick where the class can see it. Everyone gets one turn before anyone gets a second.

Can the same name be picked twice?

Only if you turn “No repeats” off. With it on, a picked name stays out of the pool until you start a new round.

How do I mark a student absent?

Use the Here checkbox next to each name in the list. Unchecked names stay on your list but are never picked, so an absent student cannot stall the lesson and the fair round does not skew.

What happens when everyone has been picked?

The page shows “Round complete — everyone has had a turn”. Press “Start a new round” to put all names back in the pool and go again.

If I paste the same name twice, does it get two chances?

Yes — each pasted line is one chance, so a name pasted twice has two chances of being picked. If you want each person to have exactly one chance, paste each name once.

Is my list uploaded or saved?

Your list is never uploaded or sent to a server. It is saved in this browser's local storage only, so it is still there when you come back on the same browser — clearing your browsing data wipes it, and it never syncs to another device.

Can I import a list from a spreadsheet or CSV?

Yes — use the CSV import button, or paste straight from a spreadsheet: one name per line, or comma-separated. The picker takes up to 500 names.

Is the pick really random and fair?

Yes. Names are picked with the browser's crypto random source (crypto.getRandomValues()) and rejection sampling, so every name in the pool has exactly the same chance. Shuffles use Fisher–Yates, not a biased sort-based shuffle.

What is the difference between this picker and the spin-the-wheel tool?

The picker draws a name and shows it; the wheel draws the same kind of list with a visible animated spin the whole room can watch. Use the picker for a quick draw, the wheel when the draw itself needs to be seen.

Why shouldn't I re-pick when I don't like the result?

Because re-picking destroys the trust the draw exists to create. The moment you draw again because the “wrong” person was picked, everyone watching concludes the draw is only random until you disapprove of it.

Can I pick more than one name at a time?

Yes — choose how many to pick, from 1 to 10. With “No repeats” on, all the picked names are different.

Does the picker work on a projector?

Yes — press “Projector mode” for fullscreen with a huge winner display, confetti and a sound toggle, so the whole room can watch the pick happen.
