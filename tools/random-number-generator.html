The problem: "random" tools that are not random enough to trust

People reach for a random number generator for things that matter a little — a raffle draw, a lottery-style pick, a classroom sample, a game. The complaints that follow them around are familiar: tools that only generate one number at a time, tools that quietly allow repeats when you needed unique numbers, tools that cap the count at a uselessly small number, and tools buried under ads. The other complaint is subtler — people are not sure the numbers are fair at all, because the tool never says how it picks them. What people want is plain: any range, as many numbers as they need, a clear unique option, and an honest statement about how the numbers are drawn.

Lottery-style draws are the classic use: pick 3 unique numbers from 1 to 49, and the draw has to be one nobody can challenge. That is also why this page draws with the browser's crypto random source instead of Math.random() — for a casual game either works, but for a draw anyone might question, the stronger source is the honest choice.

How do I generate a random number? The direct answer

Enter a minimum and a maximum, choose how many numbers you need, and press Generate — free, with no signup, and the numbers appear instantly in your browser. Both ends of the range are included, so 1 to 100 can give you 1 or 100. Tick “No repeats” for a draw where no number may appear twice.

A random number generator is a tool that picks numbers from a range with no pattern and no memory. This one draws each number from your browser's secure random source, crypto.getRandomValues, using rejection sampling — a method that throws away the few raw values that would favour smaller numbers — so every number in the range has exactly equal odds.

How to generate random numbers in 3 steps

Step 1: set your minimum and maximum — negative numbers work, so -50 to 50 is fine. Step 2: choose how many numbers you need (1 to 100) and tick "No repeats" if each number may only appear once. Step 3: press Generate, then copy all the results or download them as a .txt file.

When to allow repeats — and when not to

Allow repeats when each draw is independent, like rolling a die again or simulating coin flips. Block repeats ("No repeats") when you are drawing winners, lottery numbers or a sample — anywhere the same number appearing twice would be wrong. If you ask for more unique numbers than the range holds, for example 7 unique numbers between 1 and 6, the tool tells you plainly instead of silently giving you repeats. That is a maths limit, not a bug: there are only 6 numbers to draw from. Unique draws work by shuffling the whole range with the Fisher–Yates algorithm and taking the first numbers — never by re-rolling until something new appears.

Are these numbers random enough for a raffle?

Yes, for everyday draws — raffles, giveaways, classroom picks, games and sampling. The generator uses the same class of randomness browsers use for passwords and encryption keys, which is far stronger than the plain Math.random used by most simple tools. It is not suitable for cryptography, gambling systems or security keys: for those you need a dedicated cryptographic tool, and no web page generator should be trusted with that job.

Fair randomness — the mechanism, in one line

Every number is drawn with crypto.getRandomValues() plus rejection sampling, so every number in your range has exactly equal odds. Math.random()-only tools are fine for games, but not for a draw anyone might challenge.

FAQ

How do I generate a random number between 1 and 100?

Set minimum 1, maximum 100, count 1, and press Generate. Every value in the range is equally likely, and both ends are included, so 1 and 100 can both come up.

Can I generate random numbers without repeats?

Yes — tick “No repeats”. The tool draws without replacement, so no number appears twice. It shows an error if you ask for more unique numbers than the range holds, for example 7 unique numbers between 1 and 6.

Is a free random number generator truly random?

For classroom, raffle and game use, yes — this page draws from the browser's crypto random source (crypto.getRandomValues()) with rejection sampling, which is unpredictable. Strictly, Math.random() is pseudo-random, so a tool built on that alone is weaker.

Can random numbers be negative or decimals?

Negative whole numbers work here — set a negative minimum, such as -50 to 50. Decimals are not supported on this page: it generates whole numbers only, so use a dedicated decimal tool if you need them.

How many numbers can I generate at once?

Up to 1,000 in one click. Copy them all with one button or download them as a .txt file.

What do the statistics mean?

Mean is the average of your numbers, median is the middle value when they are sorted, and sum is the total of all of them. The page also shows the smallest and largest values drawn.

How do I get only even or only odd numbers?

Use the even/odd filter above the Generate button. The draw is limited to numbers of that kind inside your range — if the range holds no even or no odd number, the page says so instead of guessing.

Can I use this for a lottery draw?

For a casual lottery-style draw, yes — set the range (for example 1 to 49), ask for 3 unique numbers, and draw. It is not suitable for a regulated lottery or anything needing an independent audit.

Why did I get the same number twice?

Because each draw is independent — the generator has no memory. Short streaks, like the same number twice in a row, are normal randomness, not rigging. Tick “No repeats” if repeats would be wrong for your draw.

What is rejection sampling?

A method that throws away the few raw random values that would favour smaller numbers, so every number in your range has exactly equal odds. Without it, a simple remainder operation makes some numbers slightly more likely than others.

Is crypto.getRandomValues() better than Math.random()?

Yes for draws. crypto.getRandomValues() draws from the operating system's entropy pool — hardware events and timing jitter — so it is genuinely unpredictable. Math.random() is a deterministic algorithm: fine for games and animations, weaker for a draw anyone might challenge.

Can I copy or download the results?

Yes — “Copy all” copies the numbers comma-separated, and “Download .txt” saves them one per line. Both work with no signup.

Are my numbers uploaded or stored anywhere?

No. The numbers are drawn in your browser and never leave your device. Nothing is uploaded, stored on a server, or shared.

What is the difference between this and the dice roller or wheel?

This page draws numbers from a range you choose. The dice roller rolls physical-style dice with notation like 4d6kh3, and the spin-the-wheel tool picks one entry from a list you paste, visibly, in front of a room.

Why does the tool refuse more unique numbers than the range holds?

That is a maths limit, not a bug: there are only 6 numbers between 1 and 6, so 7 unique draws from that range are impossible. Widen the range or lower the count.
