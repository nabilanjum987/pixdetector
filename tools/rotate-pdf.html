The problem: a sideways page in an otherwise perfect PDF

Scanned documents are the usual culprit. One page of a scan comes out sideways or upside down, and every reader shows it that way — so you tilt your head, or you rotate the view and the next page is wrong instead. The fix people actually need is permanent: rotate the page inside the file, once, so it opens the right way up everywhere. The complaints about online rotators are familiar ones: upload limits, a paywall after the first file, tools that rotate the whole document when only two pages are wrong, and tools that re-compress the file and soften the text. What people want is a rotator that touches only the rotation, leaves the content alone, and does not make them create an account for a ten-second job.

How do I rotate a PDF?

Upload your PDF here, click a page to select it, press "Selected page left" or "Selected page right" to turn it 90 degrees at a time, then download the fixed PDF — free, with no signup and no upload, because everything runs in your browser. To fix every page at once, use "All pages left" or "All pages right" instead. A PDF rotation is a setting stored on the page, not a change to the content: the text and images are untouched, the page simply opens turned.

This tool rotates PDF pages only — that focus is the point. It does one job, it does it in your browser with pdf-lib, and the downloaded file is a real PDF with the rotation baked in, so it opens the right way up in any reader, on any device.

Why is my PDF sideways in the first place?

Most sideways PDFs come from scanners and phone cameras. A scanner saves the page the way the paper went in, and a phone stores an orientation tag instead of turning the pixels — some apps respect the tag and some do not, so the same file can look right in one app and sideways in another. Rotating the page inside the PDF fixes it everywhere at once, because the rotation is part of the file. A related problem is the "sideways" PDF that is actually a landscape page: if the page was designed wide, rotating it makes it worse. Check the preview before you download — this tool shows every page, so you can see exactly what will change.

Does rotating a PDF lose quality?

No. A 90-degree rotation only changes the page's rotation setting — the text, images and fonts are copied unchanged into the new file. There is no re-compression and no resampling, so the output is exactly as sharp as the original. That is also why this tool only offers 90-degree steps: rotating by an arbitrary angle, like 3 degrees to straighten a crooked scan, would need the whole page to be re-rendered as an image, which does lose quality. For a crooked scan, a deskew tool is the right answer, not a rotator.
