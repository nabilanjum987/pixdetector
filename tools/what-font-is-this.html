What Font Is This?

A free, honest guide to identifying any font — plus a small font generator below. Free, no signup, no watermark, and nothing is uploaded.

Honest limits — read first: this page is a guide + small font generator, not an identifier. There is no upload-to-identify button here, because a static browser-only tool has no 900,000-font server database and no OCR/AI matching engine. Custom fonts, logos and hand lettering will often have no match at all — the guide below tells you what to do instead.

The problem: you love a font and nobody will name it

Designers and fans hit this constantly: a poster, a logo, a video title — the lettering is perfect, and nobody can tell you what font it is. The usual tools frustrate in their own ways: free identifier tiers are ad-heavy and force you to label each character by hand, stylised or decorative lettering gets no match at all, and when you finally do get a name, the font often turns out to be a paid one. People want a screenshot in, a font name out, and a free lookalike if the original costs money — in seconds.

How do I find what font this is? The direct answer

There are three ways: upload a screenshot to a font identifier service, inspect the website's CSS with your browser's developer tools, or ask the designer and check the brand files. Identifiers work best on clean, standard text; CSS inspection works only for live web text; and asking the designer is the only way when the font is custom or hand-lettered.

A font identifier is a service that compares a picture of text against a large database of fonts and returns the closest matches. It works by recognising the shapes of the letters (OCR) and measuring them against known fonts. No identifier is perfect: the bigger the database and the cleaner the image, the better the match — and a browser page on its own cannot do this at all, because it has neither the database nor the matching engine.

How to find a font: the 3 real methods

Method 1 — Use a font identifier service

Crop your screenshot tightly around the text — one word is enough, with straight, high-contrast letters and no background clutter. Upload it to a font identifier (the best-known free one is WhatFontIs), label the characters it asks you to confirm, and read the results. Check the top matches against your image, and look at the "similar free fonts" the service suggests — that is where your free lookalike usually lives. If the first service finds nothing, try a second one: different services have different databases. Expect this to fail on stylised, decorative, distorted or hand-lettered type.

Method 2 — Inspect the site CSS (for text on a website)

If the font is on a web page, this method is exact. Right-click the text and choose Inspect (or press F12 and use the element picker). In the Styles panel, look for font-family — that is the font name the site loads, or the fallback stack it uses if the first font is missing. Check the Network or Fonts tab too: the loaded font files are listed there by name. This only works for live web text, never for text baked into an image.

Method 3 — Ask the designer, or check the brand files

If the font is in a logo, a poster or a brand's posts, it may be custom-made or heavily modified — in which case no database will ever match it. Ask the designer or the brand directly, or look for a brand guidelines PDF, which usually names the typefaces. When there is no match, the practical answer is a lookalike: find a free font with the same feel (same serif or sans style, similar weight and shape) rather than chasing an exact name that does not exist.

When the font turns out to be paid

An identifier match is not a licence. Many beautiful fonts cost money, and using one without the right licence — desktop, web, or commercial — can get a project in trouble. Before you use a match, check its licence and price, then search the identifier's free alternatives or a free font library for a lookalike with the same character. For a personal project, a free lookalike is almost always good enough; for client work, buy the real font or get the lookalike approved in writing.

FAQ

How can I find what font is used in an image?

Crop the text, upload the screenshot to a font identifier service, and label the letters it asks for. It compares your image against a large font database and suggests the closest matches, plus free lookalikes.

How do I find the font used on a website?

Right-click the text, choose Inspect, and look at the font-family in the Styles panel of your browser's developer tools. That shows the exact font name the site loads, or the fallback stack it uses.

Why can't a font identifier match my image?

Identifiers fail on stylised, decorative, custom or hand-lettered type, on logos with modified letters, and on low-quality or distorted images. If the font was drawn by hand or custom-made for a brand, no database has it.

What do I do if the font I found costs money?

Look for a free lookalike: identifier results usually list similar free fonts, and font sites let you filter by free licence. Never use a paid font without buying the right licence — check whether you need a desktop, web or commercial licence.

Can this page identify a font from my upload?

No. This page is a guide plus a small font generator, not an identifier — a browser-only page has no 900,000-font database and no OCR matching engine. Use method 1 in the guide for a real identification.

Is there a free font identifier?

Yes, several identifier services have free tiers. The free tiers are usually ad-heavy and ask you to label each letter manually, but they work for common fonts. Expect to try two or three services for a hard match.

Is a font generator really changing my font?

No — it swaps each letter for a look-alike Unicode character (for example, 𝐡 is U+1D421). No font file is installed and nothing is styled — the result is plain text that only looks fancy.

Why does my fancy text show as boxes (□□□)?

The viewer's device has no glyph for that character — the “tofu” problem. It is the viewer's device, not the platform, so switch to a widely supported style like bold or small caps.

Can I use fancy fonts in my Instagram username (@handle)?

No — handles allow only plain letters, numbers, periods and underscores. Style your display name and bio instead.

Why won't my styled text paste into Instagram?

It is a known Instagram app quirk — paste your text into your Notes app first, copy it again from there, and then paste into Instagram.

Will fancy text hurt my reach or SEO?

Yes, it can — search cannot read styled Unicode as the plain word, so do not style keywords or hashtags you want found.

Is styled text bad for accessibility?

Yes if overused — screen readers spell out character names or skip the text, so keep essential information in plain text.

Can I use fancy fonts with accented letters (é, ñ, ü)?

Mostly no — the styled Unicode blocks cover unaccented A–Z, a–z and 0–9 only, so accented letters fall back to plain text.

How many characters can I put in my Instagram bio with fancy fonts?

About 75 styled letters in a 150-character bio, because each styled character counts as two characters (a surrogate pair).

Which styles are safest for a permanent username?

Bold, double-struck and small caps — they clear most name filters. Glitch/Zalgo styles clear almost none.

Related questions

What is the best free font identifier? WhatFontIs has the largest free database, but its free tier is ad-heavy — try it first, then a second service if it finds nothing.

Can I identify a font from a logo? Sometimes — if the logo uses a standard font. If the letters were custom-drawn, no identifier can match them.

How do I get a font like the one in a poster? Identify the closest standard font, then search free font libraries for a lookalike with the same weight and shape.
